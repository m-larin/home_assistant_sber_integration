# Sber Smart Home (SberDevices MQTT) — интеграция для Home Assistant

Настоящая **интеграция** (custom integration) на Python, которая подключает
Home Assistant к экосистеме Сбера **исключительно по MQTT** (протокол
SberDevices «MQTT-to-Cloud»). REST/WebSocket API ни Сбера, ни HA не
используются.

После подключения ваши **светильники** (`light.*`) и **выключатели**
(`switch.*`) из Home Assistant появляются в приложении **Салют** / Сбер
онлайн и управляются голосом через умную колонку Салют. Обратная связь
работает в обе стороны:

* Салют → HA: команды «включи / выключи / яркость / температура цвета /
  цвет» превращаются в вызовы сервисов `light.turn_on/off` и
  `switch.turn_on/off`;
* HA → Салют: любое изменение состояния (из HA, сценариев, с Zigbee/Z-Wave
  выключателя и т. п.) мгновенно сообщается в облако Сбера, чтобы статус в
  приложении и ответы колонки были актуальными.

Это «родной» аналог аддона [MQTT-SberGate](../MQTT-SberGate), но
реализованный как интеграция: не нужен отдельный контейнер, REST API HA и
внешний WebSocket-клиент.

## Поддерживаемые устройства

| HA | Категория Сбера | Возможности |
|----|-----------------|-------------|
| `light.*` | `light` | вкл/выкл, яркость (`light_brightness`), температура цвета (`light_colour_temp`), цвет (`light_colour`) — функции объявляются только для тех ламп, которые их поддерживают |
| `switch.*` | `relay` | вкл/выкл (`on_off`) |

> Прочие домены (клапаны, датчики, сценарии, климат…) — следующая итерация.

## Установка

1. Скопируйте папку `custom_components/sber` в `config/custom_components/`
   вашего Home Assistant.
2. Перезапустите Home Assistant (первый раз HA сам скачает `paho-mqtt`).
3. *Настройки → Устройства и сервисы → Добавить интеграцию → Sber Smart
   Home (SberDevices MQTT)*.
4. Введите **Device ID** и **пароль интеграции**, полученные при создании
   проекта в [Сбер Studio](https://developers.sber.ru/studio/workspaces/),
   брокер оставьте по умолчанию
   (`mqtt-partners.iot.sberdevices.ru:8883`), если Сбер не указал другой.
5. Готово — устройства появятся в приложении Салют (может занять до
   минуты, облако периодически запрашивает список устройств).

Имя дома можно изменить в настройках интеграции (зубчик → Изменить
настройки).

## Как это работает

```
┌─────────────┐  down/commands    ┌──────────────────────┐
│  Sber Cloud │ ───────────────── │  SberGateway (paho)  │
│  (Салют)    │ ◄──────────────── │  в HA, MQTT TLS 8883 │
└─────────────┘  up/config        └──────────┬───────────┘
        ▲                up/status            │ HA service calls
        │                                     ▼
        └────────────  состояния  ┌──────────────────────┐
                                  │ light.* / switch.*   │
                                  └──────────────────────┘
```

* При подключении интеграция публикует список устройств в
  `sberdevices/v1/<DeviceID>/up/config` и отвечает на `config_request`,
  `status_request` и `__config` — как официальный MQTT-гейт.
* Команды приходят в `…/down/commands`, состояния уходят в
  `…/up/status`.
* Включение/выключение, яркость, температура цвета и цвет конвертируются
  в параметры сервисов HA (яркость Сбера 50–1000 → HA 1–255, температура
  цвета Сбера 0–1000 «тёплый→холодный» ≈ 2700–6500 K, цвет — HSV с
  s/v×10).

## Требования

* Home Assistant 2024.6+ (config-entries, `add_update_listener`)
* Интернет-доступ до `mqtt-partners.iot.sberdevices.ru:8883`
* Интеграция в Сбере, созданная в Сбер Studio (Device ID + пароль)

## Ограничения

* TLS-сертификат облака Сбера не проверяется (как в референсном
  SberGate) — порт 8883 использует внутренний сертификат.
* Устройства видны в Сбере, пока HA запущен и есть связь с облаком
  (характерно для MQTT-гейтов).
